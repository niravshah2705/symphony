6. Autonomous execution and local-shell risk

You acknowledge and accept the following operational risks, which are inherent to how the Software works and are documented in the Documentation:

  1. The code-writer agent executes model-generated commands using real filesystem, shell, and version-control tools, and can create commits, branches, and pull/merge requests without step-by-step human confirmation.
  2. The local shell backend is not a security sandbox. As stated in the Documentation, it is "a host shell rooted by convention, not an OS security sandbox," runs with the operating-system permissions of the account that launched the service, and "can read other paths that user can access (including the plaintext local store if it discovers its path)." Environment sanitization and the repository broker reduce routine credential leakage but do not contain adversarial or erroneous shell code.
  3. You are responsible for running the Software only against trusted repositories, tickets, and inputs, and for providing stronger isolation (for example, a dedicated container, virtual machine, or operating-system identity with a narrowly scoped workspace) where Your risk tolerance requires it.

To the maximum extent permitted by law, the Licensor is not liable for any loss of or damage to code, repositories, data, systems, or property arising from the Software's autonomous file, shell, version-control, or pull/merge-request actions.
