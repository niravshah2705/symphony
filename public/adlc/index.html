1. Frame

Capture intent, constraints, source context, and policy boundaries before any agent acts.

2. Plan

Convert goals into sequenced tickets with explicit assumptions, dependencies, and approval gates.

3. Build

Run implementation in isolated workspaces where credentials stay behind controlled services.

4. Verify

Attach tests, traces, diffs, review notes, and release evidence to the work item.

Designed for readable state, not agent theatrics.

Every stage leaves durable artifacts: plans, task context, run logs, test output, review decisions.
