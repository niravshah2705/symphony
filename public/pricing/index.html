Pricing questions

Do agents need my raw API keys?

No. Credentials stay in the per-organization encrypted vault or platform-managed storage. The egress proxy injects the real credential on outbound calls, so planner and coder containers never hold raw secrets.

Can I bring my own model keys?

Yes, on Team and Enterprise: per-organization keys for LLM providers, GitHub and Linear, resolved through the same settings service as managed keys.

What counts as a seat?

A person who opens the workspace. Agents run under the project, not under a seat.

Deploying ADLC for a whole org?

Dedicated deployment, SSO, tenant isolation and governance onboarding for the review gates.
